# ระบบแจ้งคะแนนผลการสอบนักเรียน

เว็บแอปให้นักเรียนกรอก **ชั้นเรียน + เลขที่** แล้วดูผลคะแนนแบบตื่นเต้น (ตัวเลขสุ่มวิ่งก่อนเฉลยคะแนนจริงทีละวิชา พร้อมคำให้กำลังใจ)

## โครงสร้างไฟล์
```
score-system/
├── app.py                  Flask server + API
├── db.py                   จัดการฐานข้อมูล SQLite
├── import_scores.py        นำเข้าคะแนนจากไฟล์ Excel เข้าฐานข้อมูล
├── requirements.txt
├── data/
│   └── score_template.xlsx เทมเพลตให้ครูกรอกคะแนน
├── templates/index.html
└── static/css, static/js    หน้าตาและอนิเมชันของเว็บ
```

## วิธีติดตั้ง (ทำครั้งเดียว)

ต้องมี Python 3.9+ ในเครื่อง จากนั้นเปิด Command Prompt / Terminal ในโฟลเดอร์ `score-system`:

```
pip install -r requirements.txt
```

## ขั้นตอนใช้งานแต่ละครั้งที่มีคะแนนใหม่

1. เปิดไฟล์ `data/score_template.xlsx`
2. ไปที่ชีท **"คะแนน"** → ลบแถวตัวอย่าง (แถวที่ 3 ตัวหนังสือสีเทา) → กรอกข้อมูลนักเรียนและคะแนนจริง
   - แก้ไข/เพิ่ม/ลบชื่อวิชาในแถวหัวตาราง (แถวที่ 1) และคะแนนเต็มของแต่ละวิชาในแถวที่ 2 ได้ตามต้องการ
3. บันทึกไฟล์ (จะบันทึกทับที่เดิม หรือ Save As ชื่ออื่นก็ได้)
4. นำเข้าข้อมูลเข้าระบบด้วยคำสั่ง (แทน `path/to/file.xlsx` ด้วยพาธไฟล์จริง):

   ```
   python import_scores.py path/to/file.xlsx --replace
   ```

   - `--replace` = ล้างข้อมูลเดิมทั้งหมดแล้วนำเข้าใหม่ทั้งหมด (แนะนำใช้ทุกครั้งที่มีคะแนนชุดใหม่)
   - ไม่ใส่ `--replace` = เพิ่ม/อัปเดตทับเฉพาะนักเรียนที่มีอยู่ในไฟล์ที่นำเข้า

5. เปิดเว็บเซิร์ฟเวอร์:

   ```
   python app.py
   ```

   จะเห็นข้อความ `Running on http://0.0.0.0:5000`

6. เปิดเบราว์เซอร์ไปที่ `http://localhost:5000` (เครื่องเดียวกับที่รันเซิร์ฟเวอร์)
   - หากต้องการให้นักเรียนเครื่องอื่นในโรงเรียนเข้าถึงได้ผ่าน Wi-Fi/LAN เดียวกัน ให้เปิดที่ `http://<IP เครื่องครู>:5000` เช่น `http://192.168.1.20:5000`
   - หาค่า IP เครื่องครูด้วยคำสั่ง `ipconfig` (Windows) แล้วดูที่ `IPv4 Address`

7. ปิดเซิร์ฟเวอร์ด้วยการกด `Ctrl+C` ในหน้าต่าง Terminal

## หมายเหตุ

- ฐานข้อมูลเก็บอยู่ที่ `data/scores.db` (สร้างอัตโนมัติ ไม่ต้องตั้งค่าอะไรเพิ่ม)
- หากต้องการล้างข้อมูลทั้งหมด ให้ลบไฟล์ `data/scores.db` แล้วนำเข้าคะแนนใหม่อีกครั้ง
- ระบบค้นหาด้วย **ชั้นเรียน + เลขที่** เท่านั้น ไม่ต้องกรอกชื่อ-สกุล จึงควรแจ้งนักเรียนให้จำเลขที่ตัวเองให้แม่นก่อนใช้งาน
- นี่คือเซิร์ฟเวอร์สำหรับใช้งานภายในโรงเรียน (development server) เหมาะกับจำนวนผู้ใช้พร้อมกันไม่มาก หากต้องการใช้งานจริงจังกับผู้ใช้จำนวนมาก ควรปรึกษาผู้ดูแลระบบเพื่อรันผ่าน WSGI server เช่น waitress หรือ gunicorn
